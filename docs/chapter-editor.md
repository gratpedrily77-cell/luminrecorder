# 章节清单：插入位置与拖动排序

适用于模板库的共享章节管理和完成预测中的命名章节编辑器。

## 使用方式

- 每个活动章节左侧的“＋”在这一行下方插入一个空白章节。
- 点击章节名称输入框后，该行高亮成为插入位置。再点击清单底部“新增空白章节”，新行插入在选中章节下方；按钮取得焦点不会丢失这个位置。
- 新行自动取得输入焦点。连续点击底部新增按钮，会在刚生成的新行下方继续插入。
- 没有选中章节时，底部新增按钮仍在列表末尾添加；空清单也可以直接新增。
- 拖动每行左侧的手柄调整章节顺序。拖动时显示插入位置，松开鼠标完成移动，按 Escape 取消。
- 上移和下移按钮保留，也可以聚焦按钮后按 Enter 调整顺序。
- 删除或归档选中章节后，清除其插入位置。归档章节不显示新增或拖动控件；恢复后重新显示。
- 新增和排序沿用原来的保存流程：点击“保存共享章节库”或对应目标的保存按钮后保存。

预测下一项仍按清单末尾的命名序列计算并追加；本次按选中行插入的行为针对新增空白章节。

## 实现约束

选中章节的 ID 保存在当前编辑器 DOM 中；切换或重新打开编辑器时，不沿用旧位置。拖动移动现有行，不重新创建章节，不修改章节 ID、已输入名称或历史关联。保存仍由 forecastCollectNamedItems 按当前 DOM 顺序生成 order。

行操作区使用明确的 class 定位。归档和恢复只更新操作区，保留章节明细面板。
